# NEW🌐NEWS — речь Novikova💋Forever

Актуальное решение пользователя, 4 ноября 2026: ведущая **Novikova💋Forever**
говорит **на украинском**. Профиль: `uk-UA`; код модели Supertonic: `uk`.
Старые русские MP4 остаются историческими материалами. Для нового голоса нужен
новый lip-sync и новые таймкоды окон; подмена дорожки старого MP4 не подходит.

## Проверенный полный сценарий

Як змінити орбіту астероїда? Європейський зонд «Гера» вивчатиме Діморф.
Апарат «Дарт» уже змінив його орбіту. Тепер потрібно виміряти наслідки удару
й дослідити внутрішню будову астероїда. Ці дані допоможуть точніше планувати захист Землі.

Текст для титров хранится без ударений. Отдельный `pronunciation-review.json`
содержит текст для движка, словарь, языковую метку, спорные слова и SHA-256.
Проверка по словарю не означает, что синтезатор правильно произнёс каждый звук.

## Язык и словари

| Locale | Проверка | Ограничение |
|---|---|---|
| `uk-UA` | lang-uk / ukrainian-word-stress 2.1.0, dictionary-only | омографы не выбираются наугад; неизвестные имена идут в отчёт |
| `ru-RU` | установленный Speech Studio, `text_stress`, RUAccent | применяется только к русскому тексту; новые «ё» сначала внести в редакционный текст |
| `en-US` | CMUdict 1.1.3, американские фонемы | несколько вариантов требуют контекста; фонемы в Supertonic не передаются как IPA |
| `en-GB` | отдельные британские словарные ссылки | полного британского словаря здесь нет; неизвестные слова остаются на проверке |

Просто `en` не принимается: нужно указать вариант английского. У Supertonic
`lang=en` нет гарантии выбранного акцента. Для британского выпуска нужны
соответствующий голос/движок и слуховая проверка. Английские фрагменты в
украинском выпуске оформляются отдельными блоками со своим locale либо
проверенным украинским чтением имени; русский словарь к ним не применяется.

Имя ведущей сохраняется ровно **Novikova💋Forever** в метаданных. Его нет в
данном произносимом сценарии. Ударение в фамилии не назначается автоматически.

## Настройка для следующих выпусков

Использовать существующий Supertonic 3 / F1, 8 steps, speed 1.0. В Speech Studio
0.3.5 установлен вариант Supertonic 3 int8; исходный WSL SDK использует ранее
загруженные веса. Сравнивать голоса между вариантами перед финальным выпуском.

```bash
python3 -m venv .venv-pronunciation
.venv-pronunciation/bin/pip install --no-deps ukrainian-word-stress==2.1.0
.venv-pronunciation/bin/pip install marisa-trie==1.4.1 cmudict==1.1.3
.venv-pronunciation/bin/python scripts/review_pronunciation.py \
  --text-file templates/pronunciation/hera-uk.txt --locale uk-UA \
  --overrides templates/pronunciation/context-overrides.json \
  --output /absolute/new-project/pronunciation-review.json
```

Новый отчёт не перезаписывает существующий. При изменении сценария создать
следующую версию. Контекстные правила относятся только к своему языку;
`виміряти` в другом грамматическом контексте проверить заново.

Для синтеза в существующем WSL TTS-окружении:

```bash
/home/buch/newnews-tools/tts-supertonic/.venv/bin/python scripts/synthesize_avatar_voice.py \
  --text-file templates/pronunciation/hera-uk.txt --language uk-UA \
  --pronunciation-report /absolute/new-project/pronunciation-review.json \
  --model-dir /home/buch/newnews-tools/tts-supertonic/models \
  --output /absolute/new-project/voice.wav
```

Синтез блокируется, если отчёт относится к другому тексту/языку или его
контрольная сумма не совпадает. Спорные слова разрешены только для пробного
дубля: `listeningReview=pending`, `publicationReady=false`.

## Speech Studio: исправление украинских ударений

В установленной версии 0.3.5 обнаружено: преобразование `+` перед гласной
не включает украинские `і`, `ї`, `є`. В результате `орб+іту` остаётся с плюсом
в `engine_text`, а ударение теряется. Рабочий обход: **U+0301 после гласной**
в `say` словаря проекта — `орбі́ту`. Исходный текст блока остаётся без разметки.
Проверено через реальный `text_prepare`: все ударения дошли до движка.

`scripts/speech_studio_pronunciation.py` применяет словарь к одному существующему
блоку, соответствующему полному сценарию. Глобальный словарь и другие проекты
не меняет. Отключает русский автонормализатор и RUAccent в украинском проекте.

```powershell
python scripts/speech_studio_pronunciation.py --pid PROJECT_ID `
  --report C:\path\pronunciation-review.json --synthesize
```

Команда сохраняет job ID; следить за ним через `studio_wait`. Не отправлять
повторный синтез, пока предыдущая задача ещё работает. После завершения:
`project_export` WAV 48 kHz / 16 bit; `project_package` для переносимого проекта.
Рабочий украинский проект на ПК: `bca90250b6`.

## Приёмка и логирование

1. Проверить полный текст, контекст омографов, имена, числа и аббревиатуры.
2. Проверить выход `text_prepare`: язык, слова, все ударения, отсутствие лишних плюсов.
3. Синтезировать пробный дубль и сохранить параметры, seed, хеш WAV.
4. ASR на том же языке сверяет пропуски/повторы/замены слов. ASR **не проверяет** ударения и региональный акцент.
5. Прослушать весь дубль: ударения, украинские г/ґ, и/і, ї/є, окончания,
   имена и естественность пауз. Только после этого поставить слуховое одобрение.
6. Создать lip-sync по этому WAV, пересчитать таймкоды окон, затем финальный монтаж.

`production.events.jsonl` хранит этапы `voice.pronunciation`, `speech.configure`,
`speech.engine_text`, `speech.enqueue`, `speech.synthesis`, экспорт и контроль.
Есть общий run ID, UTC, ошибки и хеши. Успех словарной проверки не подменяет
успех озвучки или редакционное одобрение. Синтез не запускает публикацию.
